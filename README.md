# Dr. Sayyid Abdul Basith V — Academic and Research Portfolio

Static personal academic website hosted with GitHub Pages.

To publish, set **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

The homepage entry is `index.html`. All HTML, CSS, JavaScript, gallery images and certificate PDFs are stored in this repository.

## Updating this site

Edit the HTML files and assets in this repository, or regenerate the website locally from your private source folder and upload the changed static files.
